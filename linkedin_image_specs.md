## 🛠️ Quick Creation Guides

### Using Canva (Easiest - 5 minutes)

1. **Create New Design**
   - Go to Canva.com
   - Click "Custom Size" → 1200 x 675 px
   - Search for "LinkedIn Post" templates (optional)

2. **Set Background**
   - Click Background
   - Click "Gradient"
   - Choose two-color gradient
   - Color 1: #1a1a2e
   - Color 2: #16213e
   - Angle: 135°

3. **Add Title**
   - Click "Text" → "Add heading"
   - Type: "AI Cold Email Agent"
   - Font: Montserrat Bold or similar
   - Size: 70
   - Color: White
   - Position at top center

4. **Add Cards**
   - Click "Elements" → Search "rectangle"
   - Add 3 rounded rectangles
   - Make them semi-transparent (adjust opacity to 10%)
   - Add white stroke/border (1px)
   - Space evenly across center

5. **Add Icons**
   - Search "document icon" → Place on Card 1
   - Search "brain icon" or "AI icon" → Place on Card 2
   - Search "email icon" → Place on Card 3
   - Color icons: Cyan for 1 & 3, Purple for 2

6. **Add Arrows**
   - Search "arrow" → Find right-pointing arrow
   - Color: Cyan
   - Place between cards
   - Duplicate for second arrow

7. **Add Tech Stack**
   - Add text box at bottom
   - Type: "FastAPI • React • LangChain • Groq • ChromaDB"
   - Font: Inter or Roboto Regular
   - Size: 18
   - Color: Light gray (#b4b4b4)

8. **Add Badge**
   - Elements → Search "badge" or create rounded rectangle
   - Background: Gold (#fbbf24)
   - Text: "200x Faster ⚡"
   - Position: Top right corner

9. **Download**
   - Click "Share" → "Download"
   - Format: PNG
   - Quality: High

### Using Figma (For Designers - 10 minutes)

1. Create frame: 1200 x 675px
2. Add linear gradient background
3. Use Auto Layout for card spacing
4. Import icons from Iconify or use shapes
5. Add effects: Glass morphism, glows, shadows
6. Export as PNG @2x

### Using PowerPoint (Quick Alternative)

3. Format Background → Gradient Fill
4. Insert Shapes → Rounded Rectangles
5. Insert Icons (Insert → Icons → Search)
6. Add Text Boxes
7. File → Save As → PNG
